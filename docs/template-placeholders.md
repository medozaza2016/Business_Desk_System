# Quotation template placeholders

Every company owns one or more template versions (`templates` table). The active version is snapshotted
into each quotation when it is issued, so editing a template never changes an existing record.

## Rendering rules

- Placeholders use double braces and **only** these characters in the name: `A-Z a-z 0-9 _`.
  Whitespace inside the braces is ignored: `{{ amount }}` and `{{amount}}` are identical.
- Values are HTML-escaped before insertion. Templates cannot inject data markup.
- Unknown placeholders render as an empty string — they never leak `{{…}}` into the printed sheet.
- Output must be a complete HTML document (`<!doctype html>` … `</html>`). The Worker injects nothing
  except an optional autoprint `<script>` immediately before `</body>`.

## Available placeholders

| Placeholder | Example | Notes |
|---|---|---|
| `{{quote_number}}` | `QA-2026-00001` | Prefix + year + 5-digit serial, or the number typed by the operator |
| `{{quote_date}}` | `05/11/2026` | Always `DD/MM/YYYY`, independent of the browser locale |
| `{{model}}` | `AUDI A8 L` | Free text, max 120 chars |
| `{{year}}` | `2012` | Free text, max 20 chars (kept as text on purpose) |
| `{{chassis}}` | `WAUZZZ4H0DN000001` | Free text, max 120 chars |
| `{{currency}}` | `AED` | From the company profile at issue time |
| `{{amount}}` | `16,500.25` | Amount in major units, thousands separated, 2 decimals |
| `{{amount_words}}` | `sixteen thousand five hundred and twenty five fils` | English words, generated by the Worker |
| `{{company_name}}` | `Challenger Cars` | `legal_name` falling back to `name` |
| `{{company_address}}` | `Al Quoz, Dubai` | May be empty |
| `{{company_phone}}` | `+971 4 000 0000` | May be empty |
| `{{company_email}}` | `quotes@example.com` | May be empty |
| `{{letterhead_url}}` | `/letterhead_background.png` | Same-origin path to the letterhead artwork |

Company values come from the snapshot stored on the quotation, not from the live company row.

## Default template

`templates/default-quotation.html` is shipped with the Worker, seeded as **version 1** for every new
company, and used when a company has no active template. It is the bilingual A4 sheet (English + Arabic),
210 × 297 mm, positioned in millimetres so browser printing matches the configured letterhead.

## Editing a template

1. Settings → **Print template** → *Reload active* to load the current HTML into the editor.
2. Edit, then **Publish version**. A new version is stored and immediately becomes the active one.
   Older versions stay in the list and can be re-activated at any time.
3. Existing quotations keep the HTML they were issued with.

Hard limits: 200,000 characters per version; a version cannot be empty.

## Content Security Policy (why some HTML is inert)

Printed sheets are served with:

```
default-src 'none'; img-src 'self' data:; style-src 'unsafe-inline'; font-src 'self' data:;
script-src <hash> | 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'self'
```

Consequences for template authors:

- **Inline `<style>` works**, external CSS does not (`style-src 'unsafe-inline'` only).
- `<script>` inside a company template never executes — this is intentional, it keeps company-authored
  HTML from running in an authenticated origin. The only script that can run is the Worker's autoprint
  snippet, allowed by its `sha256` hash when the sheet is opened with `?print=1`.
- Images must be same-origin (`img-src 'self'`) or `data:` URIs.
- Fonts must be same-origin or `data:`. The default template uses Arial (plus Tahoma/DejaVu fallbacks for
  Arabic) because system fonts print identically to what the operator sees on screen.
- No forms (`form-action 'none'`), no framing by other sites (`frame-ancestors 'self'`).

## Letterhead

`public/letterhead_background.png` ships as a neutral white placeholder so the sheet prints cleanly
before artwork exists. Replace that file with the real A4 letterhead (210 × 297 mm, 150–300 dpi) and
redeploy. The template paints it with `background-size: 100% 100%`, so the artwork must already include
the header, footer, and margins; the body content is positioned in millimetres to sit inside them.

To give a single company its own letterhead later, host the file and store a different value in
`company_snapshot_json.letterhead_url` when the quotation is created — the template needs no change
because it reads the placeholder.

### Brand line in the default template

Because the shipped letterhead is a blank placeholder, the default template ends with a discreet brand
line at 269 mm (company name, address, phone · email) so a printed sheet is never anonymous. When real
letterhead artwork that already carries the company identity is deployed, delete the `<div
class="brandline">…</div>` block in Settings → *Print template* and publish a new version — otherwise the
identity appears twice.
