# Quotation template placeholders

Every company owns one or more template versions (`templates` table). The active version is snapshotted
into each quotation when it is issued, so editing a template never changes an existing record.

## Rendering rules

- Placeholders use double braces and **only** these characters in the name: `A-Z a-z 0-9 _`.
  Whitespace inside the braces is ignored: `{{ amount }}` and `{{amount}}` are identical.
- Values are HTML-escaped before insertion. Templates cannot inject data markup.
- Unknown placeholders render as an empty string — they never leak `{{…}}` into the printed sheet.
- Output must be a complete HTML document (`<!doctype html>` … `</html>`). The Worker injects nothing
  except an optional autoprint `<script>` immediately before `</body>`.

## Available placeholders

| Placeholder | Example | Notes |
|---|---|---|
| `{{quote_number}}` | `QA-2026-00001` | Prefix + year + 5-digit serial, or the number typed by the operator |
| `{{quote_date}}` | `05/11/2026` | Always `DD/MM/YYYY`, independent of the browser locale |
| `{{model}}` | `AUDI A8 L` | Free text, max 120 chars |
| `{{year}}` | `2012` | Free text, max 20 chars (kept as text on purpose) |
| `{{chassis}}` | `WAUZZZ4H0DN000001` | Free text, max 120 chars |
| `{{comments}}` | `One owner, full service history, 2 keys.` | Free-form note typed on the quotation, max 300 chars; empty when none was entered |
| `{{currency}}` | `AED` | From the company profile at issue time |
| `{{amount}}` | `16,500.25` | Amount in major units, thousands separated, 2 decimals |
| `{{amount_words}}` | `sixteen thousand five hundred and twenty five fils` | English words, generated by the Worker |
| `{{company_name}}` | `Challenger Cars` | `legal_name` falling back to `name` |
| `{{company_legal_name_en}}` | `CHALLENGER USED CARS EXHB. LLC` | Legal name in English (`legal_name`, falling back to `name`) |
| `{{company_legal_name_en_head}}` | `CHALLENGER` | First word of it, for the accent-coloured brand word |
| `{{company_legal_name_en_tail}}` | `USED CARS EXHB. LLC` | The rest of it |
| `{{company_legal_name_ar}}` | `شالنجر للسيارات المستعملة ذ.م.م.` | Legal name in Arabic (`legal_name_ar`); empty when the profile has none |
| `{{company_legal_name_ar_head}}` | `شالنجر` | First word of it |
| `{{company_legal_name_ar_tail}}` | `للسيارات المستعملة ذ.م.م.` | The rest of it |
| `{{company_address}}` | `Al Quoz, Dubai` | May be empty |
| `{{company_phone}}` | `+971 4 000 0000` | May be empty |
| `{{company_email}}` | `quotes@example.com` | May be empty |
| `{{letterhead_url}}` | `/letterhead_background.png` | Same-origin path to the letterhead artwork |
| `{{logo_url}}` | `/api/companies/8f3…/logo?v=…` | The company logo uploaded in Settings → *Company profile*; a 1×1 transparent GIF when none exists |
| `{{logo_state}}` | `has-logo` | `has-logo` or `no-logo` — put it in a `class` attribute to switch artwork with CSS |

Company values come from the snapshot stored on the quotation, not from the live company row — with two
exceptions: `letterhead_url` and `logo_url` stay live, so re-uploading a logo can never leave a broken
image on a reprint; and a legal name missing from an older snapshot is read from the live profile, so
quotations issued before the Arabic name existed still print it.

The legal names come from **Settings → Company profile**: *Legal name (English)* (`legal_name`) and
*Legal name (Arabic)* (`legal_name_ar`). A sheet that prints its header lockup in two tones — brand word
in the accent colour, the rest in body colour — takes the `_head` / `_tail` pair instead of styling the
value itself: values stay escaped, so the template owns the markup and the profile owns the words. The
split is at the first space, which is where both live sheets break (`CHALLENGER` | `USED CARS EXHB. LLC`,
`شالنجر` | `للسيارات المستعملة ذ.م.م.`):

```html
<div class="brand-ar"><span class="accent">{{company_legal_name_ar_head}}</span> {{company_legal_name_ar_tail}}</div>
<div class="brand-en"><span class="accent">{{company_legal_name_en_head}}</span> {{company_legal_name_en_tail}}</div>
```

## Quotation comments

Every quotation carries an optional free-form note (`comments`, ≤ 300 characters) typed on the desk —
under *Comments* in the new-quotation dialog, and again on the record page (`/quote?id=…`), where it
stays editable. Newlines and runs of spaces collapse on save, because the row that prints it is a
single line. Unlike the vehicle fields the note may be cleared: an empty string reprints the row blank.

The comment is **not** frozen into the template snapshot — it is read from the quotation itself, so
fixing a typo on the record page reprints the corrected note.

A sheet prints it by asking for `{{comments}}`. The Challenger layout adds it as a fourth vehicle row:

```html
<div class="vrow comments-row">
  <div class="vlabel">Comments:</div>
  <div class="vvalue">{{comments}}</div>
  <div class="var">ملاحظات:</div>
</div>
```

```css
/* Fourth vehicle row for free-form comments. */
.vehicle { height: 43.1mm; }
.comments-row { height: 12.5mm; }
.comments-row .vvalue {
  white-space: normal;
  line-height: 1.15;
  overflow-wrap: anywhere;
}

/* Keep the valuation statement clear of the footer after adding the row. */
.statement { top: 173mm; height: 32mm; }
.statement-ar { top: 1.5mm; height: 12mm; }
.statement-line { top: 15.3mm; }
.statement-en { top: 17mm; height: 13.5mm; }
```

The last four rules reset geometry the stock sheet already overrides near the end of its own style
block, so paste them **after** that "Final A4 spacing adjustment" section — otherwise the sheet's own
`.statement` rule wins on equal specificity.

## Agreement placeholders

Agreements are their own document kind: a template is published per company **and** per kind
(`templates.kind` = `sale` or `purchase`, alongside `quotation`), and the active version is snapshotted into
the agreement when it is issued — editing the template never changes a record that has been printed.
Two rules cover both books:

- Agreement sheets borrow the whole company block from the quotation sheet (`{{company_*}}`,
  `{{letterhead_url}}`, `{{logo_url}}`, `{{logo_state}}`); everything in the table below is agreement-only.
- Unknown placeholder names render empty, so a sheet may ask for a field the desk does not keep — it simply
  prints nothing instead of leaking braces.

| Placeholder | Example | Notes |
|---|---|---|
| `{{agreement_number}}` | `SA-2026-00001` | `SA-` for a sale, `PA-` for a purchase |
| `{{agreement_date}}` | `06/11/2026` | Always `DD/MM/YYYY` |
| `{{agreement_kind}}` | `sale` | Machine value, for a `class` or a conditional stylesheet |
| `{{agreement_kind_label}}` | `Sale` | The word a sheet prints in its heading |
| `{{vehicle_model}}` | `Toyota Land Cruiser` | Required, ≤ 120 chars |
| `{{vehicle_year}}` | `2025` | Required, kept as text, ≤ 20 chars |
| `{{vehicle_chassis}}` | `JTMHV05J204123456` | Required, ≤ 120 chars |
| `{{vehicle_plate}}` | `DXB R 48213` | Optional |
| `{{vehicle_color}}` | `White` | Optional |
| `{{vehicle_odometer}}` | `41,000 km` | Optional, free text — the desk does not parse it |
| `{{vehicle_registration_place}}` | `Dubai` | Optional |
| `{{seller_name}}` | `Ahmed Al Marri` | Required |
| `{{seller_id_number}}` | `784-1985-1234567-1` | Optional, ≤ 60 chars |
| `{{seller_phone}}` | `+971 50 123 4567` | Optional |
| `{{seller_address}}` | `Al Barsha 2, Dubai` | Optional |
| `{{buyer_name}}` | `Sunrise Trading LLC` | Required |
| `{{buyer_id_number}}` | `1054721` | Optional, ≤ 60 chars |
| `{{buyer_phone}}` | `+971 55 765 4321` | Optional |
| `{{buyer_address}}` | `Deira, Dubai` | Optional |
| `{{intermediary_name}}` | `Challenger Motors` | Optional; empty when the deal had no broker |
| `{{intermediary_id_number}}` | `7733105` | Optional, ≤ 60 chars |

### Hiding a field the desk left blank

Every optional agreement field prints a companion `<field>_state` token: `has-value` when the record
carries something, `no-value` when it is blank. Put it in the element's `class` and let CSS drop the
element. The Worker only substitutes values — it never removes markup — so the sheet stays in charge of
what an empty field looks like.

| Optional field | Companion token |
|---|---|
| `{{vehicle_plate}}` `{{vehicle_color}}` `{{vehicle_odometer}}` `{{vehicle_registration_place}}` | `{{<field>_state}}` |
| `{{seller_id_number}}` `{{seller_phone}}` `{{seller_address}}` | `{{<field>_state}}` |
| `{{buyer_id_number}}` `{{buyer_phone}}` `{{buyer_address}}` | `{{<field>_state}}` |
| `{{intermediary_name}}` `{{intermediary_id_number}}` `{{intermediary_phone}}` `{{intermediary_address}}` | `{{<field>_state}}` per row, plus `{{intermediary_state}}` for the whole block |
| `{{notes}}` | `{{notes_state}}` = `has-notes` / `no-notes` |

```html
<div class="party">
  <div class="party-role">Seller</div>
  <div class="party-name">{{seller_name}}</div>
  <div class="party-row {{seller_id_number_state}}"><span>ID / Passport</span><span>{{seller_id_number}}</span></div>
  <div class="party-row {{seller_phone_state}}"><span>Phone</span><span>{{seller_phone}}</span></div>
  <div class="party-row {{seller_address_state}}"><span>Address</span><span>{{seller_address}}</span></div>
</div>

<!-- the broker is a party like the two principals, and optional as a whole -->
<div class="party intermediary {{intermediary_state}}">
  <div class="party-role">Intermediary</div>
  <div class="party-name">{{intermediary_name}}</div>
  <div class="party-row {{intermediary_phone_state}}"><span>Phone</span><span>{{intermediary_phone}}</span></div>
</div>
```

```css
/* a row the operator left blank prints nothing at all: no label, no gap */
.party-row.no-value { display: none; }
table.grid tr.no-value { display: none; }

/* the whole broker block, and its signature line, disappear when no broker was recorded */
body.no-intermediary .party.intermediary { display: none; }
body.no-intermediary .intermediary-sign { display: none; }
```

The shipped agreement sheets use exactly this pattern (see `templates/default-sales-agreement.html`).

Money is never conditional: a sheet always prints the agreed price, the deposit and the balance, because a
deposit of `0.00` is a fact about the deal rather than a blank. `{{agreement_kind}}` is the token for
switching wording between the two books (`sale` / `purchase`):

```css
body.purchase .terms-sale { display: none; }
body.sale .terms-purchase { display: none; }
```

Amounts are always rendered with the record's currency beside them by the sheet itself
(`{{currency}} {{full_amount}}`), because the Worker only formats the number.

## Company logo and watermark

One image serves both jobs. Upload it in **Settings → Company profile → Brand logo** (PNG, JPEG or WebP,
≤ 512 KB) and print it wherever the template asks for `{{logo_url}}`:

```html
<!-- header mark -->
<div class="brand-logo {{logo_state}}">
  <img class="logo-builtin" src="data:image/webp;base64,…" alt="">
  <img class="logo-upload" src="{{logo_url}}" alt="">
</div>

<!-- faint watermark, same file -->
<div class="watermark {{logo_state}}">
  <img class="wm-upload" src="{{logo_url}}" alt="">
</div>
```

```css
.brand-logo.has-logo .logo-builtin, .brand-logo.no-logo .logo-upload { display: none; }
.watermark.has-logo .wm-upload { /* a removed logo prints nothing */ }
.watermark { opacity: .22; }        /* watermark strength */
```

Why two tokens:

- `{{logo_url}}` degrades to a transparent 1×1 GIF instead of an empty `src`, so a template that prints
  it while no logo is uploaded never shows a broken-image icon.
- `{{logo_state}}` lets a template keep its own built-in artwork (the shipped default keeps the
  Challenger winged-C) and drop it the moment a company logo exists. Both values are plain text, so they
  stay inside the "values are HTML-escaped" rule.

Templates published **before** this feature do not contain the tokens: the upload still succeeds, the API
returns `template_uses_logo: false` and the desk warns you. Add the block above to the live template and
publish a new version. The Marshall Auctions template is an example of a company whose artwork lives
entirely in its own SVG; it simply never references `{{logo_url}}`.

`templates/challenger-cars-quotation.html` is the Challenger Cars A4 sheet with the slot wired in — a
worked example of converting an existing template. It keeps the built-in winged-C as the `no-logo`
fallback for the header mark and prints the upload as a 10 %-opacity watermark in the free band of its
footer (between the signature row and the contact block). It is a reference copy only: it is not imported
or seeded, so it is never bundled into the worker.

The image is same-origin and public to read, so it renders even inside the sandboxed preview iframes
(the print CSP already allows `img-src 'self' data:`); uploaded SVGs are refused by the API, so a logo can
never be a script-bearing document.

## Default template

`templates/default-quotation.html` is shipped with the Worker, seeded as **version 1** for every new
company, and used when a company has no active template. It is the bilingual A4 sheet (English + Arabic),
210 × 297 mm, positioned in millimetres so browser printing matches the configured letterhead.

## Building a sheet from scratch

The short form of this section is in the app: **Settings → Print templates → How to build this sheet**, a
collapsible panel under the editor that lists every placeholder for the tab you have open. The long form:

1. **Start from a working page.** Pick the tab and press *Load built-in* — the bundled sheet for that kind is
   a complete, valid document. Redesign its markup and CSS rather than starting from an empty buffer; the
   millimetre geometry of an A4 page is the part that is easiest to get wrong.
2. **Write a complete document.** `<!doctype html>` … `</html>`. The Worker substitutes values and, for
   `?print=1`, appends its autoprint snippet before `</body>`. It injects nothing else.
3. **Put the values in with `{{token}}`.** Double braces, the token name, double braces — names use
   `A-Z a-z 0-9 _` only. Values are HTML-escaped, so a token never becomes markup: the template owns the
   tags and the record owns the text.
4. **Style it inline.** One `<style>` block inside the document; no external CSS, no CDN, no web fonts. A4 is
   210 × 297 mm — position with millimetres so browser printing matches the letterhead, and keep the page to
   a single sheet (`overflow: hidden` on the page wrapper).
5. **Decide what an empty field looks like.** Optional fields carry their companion `*_state` class; the
   sheet, not the Worker, decides whether to drop the row, keep the label or print a dash.
6. **Keep it inert.** No `<script>` (the CSP refuses it), no forms, no remote images — same-origin images and
   `data:` URIs only. A sheet cannot fetch anything at print time, so everything it shows must already be in
   the record or the company profile.
7. **Proof, then publish.** *Preview edits* opens the buffer in its own tab, rendered with sample values
   (next `SA-…` / `PA-…` number, sample parties including a broker, sample vehicle and money) without saving.
   When the proof reads right, **Publish version** makes it live for new records only; issued ones keep their
   snapshot.

Tokens are flat substitutions: there are no loops, conditionals, filters or arithmetic. Anything that
repeats, such as the vehicle table, is written out once in the template; anything that has to adapt is done
with the state classes above.

## Editing a template

Settings → **Print templates** is one studio with three tabs — *Quotation*, *Sale agreement*, *Purchase
agreement*. Each tab keeps its own versions, its own live page and its own editor, so editing an agreement
sheet never touches the quotation page.

1. Pick the tab. *Load built-in* puts the bundled sheet for that kind into the editor; *Reload live* puts the
   current live version there instead.
2. Edit, then **Publish version**. A new version is stored and immediately becomes the live one. Older
   versions stay in the list and can be re-activated at any time.
3. **Preview edits** proofs the buffer without saving, in a tab of its own (so a full A4 page never sits on
   top of the editor). Agreement tabs proof with sample parties (seller, buyer, broker), the sample vehicle
   and the kind's next number (`SA-…` / `PA-…`), so every agreement placeholder is visible before it goes live.

Existing quotations and agreements keep the HTML they were issued with; a tab with no published version
prints the built-in sheet for that kind.

Hard limits: 200,000 characters per version; a version cannot be empty. The live version cannot be deleted —
activate another one first, and records that used it keep their snapshot.

## Content Security Policy (why some HTML is inert)

Printed sheets are served with:

```
default-src 'none'; img-src 'self' data:; style-src 'unsafe-inline'; font-src 'self' data:;
script-src <hash> | 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'self'
```

Consequences for template authors:

- **Inline `<style>` works**, external CSS does not (`style-src 'unsafe-inline'` only).
- `<script>` inside a company template never executes — this is intentional, it keeps company-authored
  HTML from running in an authenticated origin. The only script that can run is the Worker's autoprint
  snippet, allowed by its `sha256` hash when the sheet is opened with `?print=1`.
- Images must be same-origin (`img-src 'self'`) or `data:` URIs.
- Fonts must be same-origin or `data:`. The default template uses Arial (plus Tahoma/DejaVu fallbacks for
  Arabic) because system fonts print identically to what the operator sees on screen.
- No forms (`form-action 'none'`), no framing by other sites (`frame-ancestors 'self'`).

## Letterhead

`public/letterhead_background.png` ships as a neutral white placeholder so the sheet prints cleanly
before artwork exists. Replace that file with the real A4 letterhead (210 × 297 mm, 150–300 dpi) and
redeploy. The template paints it with `background-size: 100% 100%`, so the artwork must already include
the header, footer, and margins; the body content is positioned in millimetres to sit inside them.

To give a single company its own letterhead later, host the file and store a different value in
`company_snapshot_json.letterhead_url` when the quotation is created — the template needs no change
because it reads the placeholder.

### Brand line in the default template

Because the shipped letterhead is a blank placeholder, the default template ends with a discreet brand
line at 269 mm (company name, address, phone · email) so a printed sheet is never anonymous. When real
letterhead artwork that already carries the company identity is deployed, delete the `<div
class="brandline">…</div>` block in Settings → *Print template* and publish a new version — otherwise the
identity appears twice.

## Known limitations of the default sheet

- **Amount in words is English only.** The Arabic sentence carries the figure (`{{amount}}`) and the Arabic
  unit "درهم إماراتي", so the default sheet assumes an AED company. A company trading in another currency
  should edit that sentence in its own template version.
- The sheet is a **single page by design** (`overflow:hidden`, fixed 297 mm). Long model or chassis values
  wrap inside `.vvalue`, but extreme values can clip.
- Numbers use Western Arabic digits in both languages, matching the reference sheet.
