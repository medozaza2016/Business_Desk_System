How to build this sheet placeholders, print rules, and what a redesign may not do
  1. Start from a page that already prints. Load built-in drops the bundled A4 sheet for this tab into the editor; redesign its markup and CSS instead of starting from an empty buffer.
  2. Ship a complete document. <!doctype html> … </html>. The Worker only substitutes values, and appends its autoprint snippet for ?print=1 — nothing else.
  3. Write values as {{token}}. Names use letters, digits and _ only; whitespace inside the braces is ignored. Values are HTML-escaped, so the template owns the tags and the record owns the text.
  4. Style it inline. One <style> block, no external CSS, no web fonts. A4 is 210 × 297 mm: position in millimetres and keep the page to a single sheet.
  5. Let blank fields disappear. Every optional field prints a companion {{field_state}} (has-value / no-value); put it in the row's class and hide that class in CSS. Same idea for {{intermediary_state}} (the whole broker block) and {{notes_state}}.
  6. Keep it inert. No <script> (the print CSP refuses it), no forms, no remote images — same-origin and data: URIs only.
  7. Proof, then publish. The Preview tab renders whatever is in the buffer — sample parties, a sample vehicle and the next number — and nothing is saved. Switch back to HTML to keep editing; Publish version makes the buffer live for new records only.

Tokens are flat substitutions — there are no loops, conditionals, filters or arithmetic. Anything that repeats is written out once in the template; anything that has to adapt is done with the state classes above. Money is never hidden: the agreed price, the deposit (even 0.00) and the balance always print.
